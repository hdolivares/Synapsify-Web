## Overview

This guide helps you configure proper rDNS/PTR records for email delivery from your VPS. Proper reverse DNS is **critical** for email deliverability and preventing emails from being marked as spam.

## Critical Email Configuration Requirements

### 1. rDNS/PTR Record (Reverse DNS)

**What it is:** A PTR record maps your IP address back to a hostname. This is checked by receiving mail servers.

**Best Practice:** Set rDNS to match your MX record hostname.

**Recommended Setup:**
- **rDNS should point to:** `mail.mapio.ai`
- **Forward DNS (A record):** `mail.mapio.ai` → `104.237.6.152`

### 2. DNS Records Required

#### For mapio.ai Domain:

```

## Step-by-Step Setup

### Step 1: Configure DNS Records (In Your DNS Provider)

**⚠️ CRITICAL:** `mail.mapio.ai` **MUST** be DNS-only (gray cloud in Cloudflare), NOT proxied!

1. **Log into your DNS provider** (Cloudflare, Namecheap, etc.)

2. **Add/Update A Record:**
   - **Type:** A
   - **Name:** `mail`
   - **Content:** `104.237.6.152`
   - **Proxy Status:** **DNS Only** (gray cloud) ⚠️ **NOT Proxied**
   - **TTL:** 300 (5 minutes) or Auto

3. **Add SPF Record:**
   - **Type:** TXT
   - **Name:** `@` (or `mapio.ai`)
   - **Content:** `v=spf1 ip4:104.237.6.152 a:mail.mapio.ai ~all`
   - **TTL:** 300 or Auto

4. **Verify MX Record:**
   - **Type:** MX
   - **Name:** `@` (or `mapio.ai`)
   - **Priority:** 10
   - **Value:** `mail.mapio.ai`

### Step 2: Request rDNS/PTR Record from Your VPS Provider

**rDNS/PTR records are set by your VPS hosting provider, NOT in your DNS provider.**

#### Option A: Vultr (If using Vultr)

1. Log into **Vultr Control Panel**
2. Go to **Products** → **Servers**
3. Click on your server
4. Go to **Settings** → **IPv4**
5. Find your IP `104.237.6.152`
6. Click **Edit** next to Reverse DNS
7. Enter: `mail.mapio.ai`
8. Click **Save**

#### Option B: DigitalOcean (If using DigitalOcean)

1. Log into **DigitalOcean Control Panel**
2. Go to **Networking** → **Domains**
3. Click on your IP address
4. Click **Edit** next to Reverse DNS
5. Enter: `mail.mapio.ai`
6. Click **Save**

#### Option C: VPSDime (Your Provider)

**VPSDime requires you to contact their support team to set up rDNS/PTR records.**

**Steps:**

1. **First, ensure forward DNS is configured:**
   - Verify `mail.mapio.ai` has an A record pointing to `104.237.6.152`
   - This MUST be done BEFORE requesting rDNS (VPSDime requires it)

2. **Open a support ticket with VPSDime:**
   - Log into your VPSDime account
   - Go to **Support** → **Submit Ticket**
   - **Subject:** "Request Reverse DNS (PTR) Record Setup"
   - **Priority:** Normal

3. **Include this information in your ticket:**
   ```

## Important Notes

### ⚠️ Cloudflare Proxy Warning

**DO NOT proxy `mail.mapio.ai` through Cloudflare!**

- Email servers need direct IP connections
- Cloudflare proxy breaks email delivery
- Set `mail.mapio.ai` to **DNS-only** (gray cloud)

### Multiple Domains

If you're sending emails from both `mapio.ai` and `synapsify.app`:

1. **Option 1:** Use separate mail subdomains
   - `mail.mapio.ai` → `104.237.6.152`
   - `mail.synapsify.app` → `104.237.6.152`
   - Set rDNS to `mail.mapio.ai` (primary domain)

2. **Option 2:** Use one mail server for both
   - Set rDNS to `mail.mapio.ai`
   - Configure SPF records for both domains to include the IP

## Troubleshooting

### rDNS Not Working

1. **Wait 24-48 hours** after requesting rDNS from provider
2. **Verify forward DNS** is correct first
3. **Contact VPS provider** if rDNS doesn't update

### Emails Going to Spam

1. Check SPF, DKIM, DMARC records
2. Verify rDNS matches forward DNS
3. Check sender reputation: https://mxtoolbox.com/blacklists.aspx
4. Warm up IP address gradually (start with low volume)

### Cannot Send Emails

1. Check port 25 is open: `telnet mail.mapio.ai 25`
2. Check Postfix logs: `tail -f /var/log/mail.log`
3. Verify firewall allows port 25
